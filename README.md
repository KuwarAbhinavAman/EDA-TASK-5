# Titanic Dataset Exploratory Data Analysis (EDA)

This project involves a comprehensive exploratory data analysis of the Titanic dataset, focusing on uncovering patterns related to passenger survival during the disaster.

## 📊 Objective

To analyze the Titanic passenger data using visual and statistical methods to understand:
- Survival rates across different demographics
- Influence of features like gender, age, fare, class, family size, and embarkation port
- Missing values and correlations in the dataset

## 🗂 Dataset

- Source: [Kaggle Titanic Dataset](https://www.kaggle.com/competitions/titanic/data)
- File Used: `train.csv`

## 🛠 Tools and Libraries

- Python 3
- Pandas
- NumPy
- Matplotlib
- Seaborn
